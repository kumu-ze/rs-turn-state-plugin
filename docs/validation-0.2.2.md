# 0.2.2 调度与自动保存验证

## 版本和接口

本版本属于 kumu-ze 的独立 Turn-State 实验插件，宿主是 codex/plugin-host fork，最低宿主 `3.12.1-plugin.2 / API 1`；它不是上游官方内置功能。插件版本为 0.2.2，未增加宿主能力或 RPC 方法，运行数据格式未更改。

仍调用 `accounts.list/get` 获取非敏感账号快照，`responses.probe` 发起宿主实现的固定探测，`network.exit` 独立采样出口，以及 `proxies.list/resolve` 读取管理员代理。OAuth 凭据保留在宿主；代理解析可能向可信原生插件传递认证 URL。页面仅通过 sandbox iframe 的 postMessage 调用 `admin.*`，代理 URL 和票原文不出现在 panel 投影中。

## 根因和行为

0.2.1 的手动入口只调用一次 probe，不会按入口配置发满并发。自动调度虽生成了多个 future，但各 future 取得账号后重复检查冷却，先完成的一发可能把同批迟到的 future 拦掉。持续模式已有独立批次，重复实现使行为不一致；原来的工作流测试只判断最终命中，没有测量同时在途数。

0.2.2 统一批次规划与冷却，账号/模型有批次互斥。每入口按剩余并发规划，重复网络入口共享最小限额，全插件打标探测共用 12 槽信号量。12 槽与宿主每插件的 16 个回调槽是不同层级：账号快照、出口采样和管理读取也消耗宿主回调预算。宿主暂时不可用会按现有失败/退避处理；没有无限创建任务。

首个命中会阻止仍在等待账号信息的槽发送网络探测；已发送的探测保留额度并安全写日志。显式停止持续任务立即取消后续批次，现有网络请求收尾后才释放额度。保存改变策略版本后，旧版本结果不能成为有效票。退出插件进程依然会终止本地任务，不能保证外部服务在同一瞬间停止已接收的请求。

## 验证记录

2026-09-20 在独立 NAS 构建目录测试，未调用生产账号/真实上游探测。Rust 单元测试通过，严格 Clippy（`--all-targets -- -D warnings`）通过；前端 ESLint、vue-tsc 和生产构建通过。

`tests/concurrency.py` 启动真实原生 worker，通过线程 HTTP mock 记录每个探测进入/退出时刻和峰值：

- 手动池和指定单入口均测得同时在途 3；panel 的 inFlight 同时为 3。
- 重复提交同账号模型批次被拒绝，不新增探测。
- 重复入口共用最低限额、禁用入口不发请求；5 个并发 3 的入口下全局实测峰值为 12，每入口不超过 3。
- 持续模式真实并发 3，命中后停止；显式停止时在途请求仍占用配额，不能趁停止再发新批次。
- 第一发快速命中、其余账号快照延迟时，只发出第一发。第一发快速未命中时，自动批次仍发完 3 个槽，避免同批冷却误拦截。
- 在途时保存目标长度，所有旧版本结果均未被采纳。

`tests/workflow.py` 继续覆盖身份隔离、票复用、持久化/重启、代理导入、出口采样、日志清理、持续模式及业务活跃时自动补票。

`tests/ui-harness.html` 是纯本地模拟宿主，不含凭据。通过 Playwright CLI 执行 `tests/ui-autosave.js` 验证：800ms 后自动保存；保存响应期间编辑不会丢失并会顺序再存；定时刷新保留非法中间输入与焦点；保存失败保留草稿、手动重试成功；外部 revision 变化不覆盖其他页面设置；显式重载确认有效。桌面和手机视口均检查。

复现 UI 检查：先构建 frontend，仓库根运行 `python3 -m http.server 5197 --bind 127.0.0.1`，在独立 Playwright 会话打开 `http://127.0.0.1:5197/tests/ui-harness.html`，执行 `playwright-cli run-code --filename tests/ui-autosave.js`。

## 限制与风险

- 手动操作现在按配置发一批，可能比旧版本产生更多请求与用量；选择单入口并发 1 可维持一次请求。
- 修改策略会使同版本检查下的在途结果失效；自动保存不会绕过该安全边界。
- 清空整个池继续需要显式保存。失败/非法输入不会自动落盘，iframe 关闭后未提交草稿可能丢失；请查看保存状态。
- 连续编辑期间失败草稿不会被轮询覆盖，但多页面冲突不自动合并；需重载或手工保留自己的更改再应用。
- 真实进程测试的网络对象是 mock。没有本次生产账号打标验收、长期压力数据或上游有效期保证；原生插件仍不是操作系统沙箱。
